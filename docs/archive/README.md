## Archive sections

- `architecture/` — older design snapshots and issue-era GUI architecture.
- `architecture-review/` — architecture review findings, remediation records,
  and dated ownership snapshots.
- `migrations/` — historical upgrade/migration procedures.
- `qa/` — dated ticket-specific qualification records.
- `tasks/` — historical task/handoff records, not live assignments.
- `documentation/` — dated documentation audits and repository cleanup records.
- `plans/` — implementation plans and ticket-era planning material.
- `provider-history/` — provider-specific implementation-era documents now
  superseded by the consolidated Metadata & Provider Guide.
- `provider-research/` — feasibility/research reports.
- `research/` — upstream requirements and other bounded research artifacts.

Archived documents are preserved rather than deleted so their evidence,
decisions, and engineering history remain available.
